# design-previews/ — READ FIRST

Everything in this folder is a DESIGN PREVIEW ONLY. Mockup PNGs are
NOT pushed via the text-only GitHub route — they are listed here
for manual upload, and they are NEVER main README images.
Main repo images must be real product/schematic photos.
Mockup values are placeholders, not live data, unless a mockup
says otherwise. Icons are generic drawn glyphs, NOT Apple/Google/
Spotify logos, NOT copied assets. No Apple SF font (Inter in
mockups, Montserrat on-device).
